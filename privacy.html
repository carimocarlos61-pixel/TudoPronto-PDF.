Política de privacidade

As ferramentas processam os documentos no navegador do utilizador. O código desta versão não envia os ficheiros selecionados para um servidor do TudoPronto PDF nem os armazena num backend.

Este site é estático e pode ser alojado por terceiros, como GitHub Pages ou Cloudflare Pages. Esses fornecedores podem tratar dados técnicos de acesso de acordo com as respetivas políticas.

Se forem ativados serviços de publicidade, análise, métricas, formulários externos ou cookies, esta política deverá ser atualizada para identificar os fornecedores, os dados tratados, as finalidades, os prazos de retenção e os mecanismos de consentimento aplicáveis. Não ative publicidade antes de configurar e publicar as divulgações e consentimentos legalmente exigidos.

O utilizador deve evitar usar ferramentas web para documentos especialmente confidenciais ou sujeitos a requisitos de segurança específicos.
